# 자기소개 웹사이트

이 저장소는 GitHub Pages에서 바로 공개할 수 있도록 최상위 루트에 `index.html`을 두고 있습니다.

## 로컬 실행

```bash
cd /workspaces/tornaa018.github.io
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 열면 사이트를 볼 수 있습니다.

## GitHub Pages 배포

GitHub 저장소 이름이 `tornaa018.github.io` 이면 아래 주소로 접속할 수 있습니다.

```text
https://tornaa018.github.io/
```

GitHub 저장소에서 Settings → Pages에서 기본 브랜치와 루트 경로를 확인하면 됩니다.
